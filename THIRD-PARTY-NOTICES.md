# Dependencies and technical references

The source projects use .NET 10, WPF and Windows Forms, with no third-party NuGet runtime packages. Self-contained Windows releases include Microsoft .NET runtime components; their bundled `LICENSE.txt` and `ThirdPartyNotices.txt` are retained. See [dotnet/runtime](https://github.com/dotnet/runtime) and [dotnet/wpf](https://github.com/dotnet/wpf).

The project researched [VPet](https://github.com/LorisYounger/VPet) and [BongoCat](https://github.com/ayangweb/BongoCat) for general architecture and window/state-management ideas. The implementation here was written independently; no code or artwork from those repositories was copied. Their licenses do not license this project's character images.

Character imagery is documented separately in [ASSETS.md](ASSETS.md). AI brand/product names identify optional passive bindings and do not imply endorsement.
